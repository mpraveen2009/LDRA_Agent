✅ Quality Gate

TCF Validator: The Bouncer

What It Checks

  • 🔍 Structure — proper Begin/End blocks, no empty test cases
  • 📋 Required fields — File, Procedure, Procedure Number
  • 🏷️ Variable universe — every variable active or removed per test case
  • 🎯 Usage codes — G (global input), H (expected output), I/O/P
  • 🧮 Exhaustiveness — all 8 functions, all branches covered
  • 🔗 Struct members — sMscFaultsList[54..61] with Packed = T
